# 接口文档

> 课程设计选题：题目三-个人记账本（收支管理+图表统计）
> 基地址：`http://127.0.0.1:5001`
> 认证方式：**Session Cookie**（Flask-Login），登录后浏览器自动携带；写操作额外要求 **CSRF Token**。
> 文档中的示例均与 `app/auth/routes.py`、`app/ledger/routes.py`、`app/stats/routes.py`、`app/errors.py` 的实际路由一致。

---

## 一、通用约定

### 1.1 认证与权限

- 所有业务页面与接口都要求登录（`@login_required`），未登录时：
  - **页面请求**：302 重定向到 `/login?next=原路径`；
  - **API 请求**（路径以 `/api/` 开头，或 `Accept: application/json`）：返回 `401 {"code":1,"msg":"登录已过期，请重新登录"}`。
- 所有数据查询都以 `current_user.id` 过滤，不存在跨用户读写的可能；访问不属于自己的记录（如 `/records/999/edit`）返回 404 而不是 403，避免泄露"该 id 是否存在"。

### 1.2 统一响应结构

**成功**（HTTP 200）：

```json
{ "code": 0, "msg": "ok", "data": { } }
```

**失败**（HTTP 400 / 401 / 403 / 404 / 500）：

```json
{ "code": 1, "msg": "金额格式不对：只能是正数且最多两位小数（如 12.50）", "field": "amount" }
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | int | `0` 成功，`1` 失败 |
| msg | string | 可直接展示给用户的中文提示；成功时为 `"ok"` |
| data | any | 成功时的业务数据，失败时不存在 |
| field | string | 可选，具体出错的字段名（`amount` / `record_date` / `note` / `type` / `category_id` / `account_id` / 参数名），供前端定位输入框 |

### 1.3 错误码表

| HTTP 状态码 | 含义 | 典型场景 | 响应体 |
| --- | --- | --- | --- |
| 400 | 参数错误 / 表单令牌失效 | 金额格式错、日期越界、`page=abc`、CSRF token 缺失或过期 | `{"code":1,"msg":"...","field":"可选"}`（API）或中文错误页（HTML） |
| 401 | 未登录 / 会话过期 | 未登录访问 `/api/stats/*` | `{"code":1,"msg":"登录已过期，请重新登录"}` |
| 403 | 无权限 / 越权 | 访问无权限资源 | `{"code":1,"msg":"没有权限执行该操作"}` |
| 404 | 资源不存在 | 编辑/删除不存在的记录、访问不存在的页面 | `{"code":1,"msg":"资源不存在"}` |
| 413 | 请求体过大 | POST 内容超过 2MB | `{"code":1,"msg":"请求体过大"}` |
| 500 | 服务器异常 | 未捕获异常（会先回滚事务并写日志） | `{"code":1,"msg":"服务器开小差了，请稍后再试"}` |

### 1.4 CSRF Token 获取与使用

服务端开启了 Flask-WTF 全局 CSRF 保护，**所有 POST 请求**都必须携带 token。

1. 页面模板中已注入 meta 标签（`app/templates/base.html`）：

```html
<meta name="csrf-token" content="{{ csrf_token() }}">
```

2. 表单提交使用隐藏域（普通 HTML 表单）：

```html
<input type="hidden" name="csrf_token" value="{{ csrf_token() }}">
```

3. Ajax 请求把 token 放进请求头 `X-CSRFToken`：

```javascript
const token = document.querySelector('meta[name="csrf-token"]').content;

await fetch('/api/records', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-CSRFToken': token,
    'X-Requested-With': 'XMLHttpRequest',
  },
  body: JSON.stringify({ amount: '23.50', type: 'expense', record_date: '2026-10-29' }),
});
```

4. token 失效（页面停留过久、会话变化）时，页面请求会被导向 `GET /csrf-error`（返回 400 中文错误页并 flash 提示刷新）；API 请求返回 `400 {"code":1,"msg":"表单令牌已失效，请刷新页面后重试"}`。

## 二、页面接口

以下接口返回 HTML 页面（Jinja2 服务端渲染），不是 JSON API。它们没有 JSON 响应体，因此以表格形式给出"方法 / URL / 认证要求 / 参数 / 返回页面"；需要请求示例与成功/失败 JSON 的接口是第三节的数据接口。

### 2.1 概览首页

`GET /` ｜ 需要登录

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| 无 | - | - | - | 固定展示"当前自然月"的概览 |

返回：HTML 页面，包含本月收入/支出/结余/笔数、环比同比、预算进度、最近 8 条记录、本月支出 TOP5、快速记账表单。

### 2.2 流水列表

`GET /records` ｜ 需要登录

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| year | query | int | 否 | 年份，2000~2100；非法值降级为空 |
| month | query | int | 否 | 月份 1~12；配合 year 使用，单独传月份时取当前年份该月 |
| type | query | string | 否 | `expense` / `income`；其它值降级为空 |
| category_id | query | int | 否 | 分类 id；非数字降级为空 |
| keyword | query | string | 否 | 备注关键词，模糊匹配，最多取前 50 个字符 |
| page | query | int | 否 | 页码，默认 1，每页 10 条；非法值回落第 1 页并 flash 提示 |

返回：HTML 页面，包含筛选结果、分页条、当前筛选条件下的收入/支出/结余合计。

> 分页与导出链接由模板 global 函数 `records_url(page=...)`、`export_url()` 统一生成：它们在服务端拼接 query 参数并保留当前筛选条件，避免在 Jinja2 模板里手写 `?a=1&b=2` 带来的参数编码与遗漏问题（Jinja2 也不支持 `**kwargs` 语法）。

### 2.3 记一笔 / 编辑

`GET|POST /records/create` ｜ 需要登录
`GET|POST /records/<rid>/edit` ｜ 需要登录（记录必须属于当前用户，否则 404）

表单字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| amount | string | 是 | 正数、最多两位小数、上限 99999999.99 |
| type | string | 是 | `expense` / `income` |
| category_id | int | 否 | 分类 id，必须属于当前用户且类型与 `type` 匹配 |
| account_id | int | 否 | 账户 id，必须属于当前用户 |
| record_date | string | 是 | `YYYY-MM-DD`，不早于 2000-01-01、不晚于今天 |
| note | string | 否 | 备注，最多 200 字 |

成功：302 重定向到 `/records` 并 flash 成功提示；失败：重新渲染表单（400），回填已填内容并展示字段错误。

### 2.4 删除记录

`POST /records/<rid>/delete` ｜ 需要登录 ｜ 需要 CSRF

无请求体参数。成功：302 重定向回来源页（`Referer`，保留筛选条件）；记录不存在或非本人：404。

### 2.5 分类管理

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/categories` | 分类管理页（支出/收入两组） |
| POST | `/categories/create` | 新增分类，字段：`name`（≤20 字）、`type`、`icon`（emoji，≤8 字符）、`color`（`#RGB` 或 `#RRGGBB`） |
| POST | `/categories/<cid>/update` | 修改分类名称/图标/颜色（`name`、`icon`、`color`） |
| POST | `/categories/<cid>/delete` | 删除自定义分类；系统预置分类不可删，提示"可改名或改颜色" |

删除分类后，该分类下的历史账目**保留**并显示为"未分类"（外键 `ON DELETE SET NULL`）。同名同类型分类会返回 400 并提示。

### 2.6 账户管理

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/accounts` | 账户管理页 |
| POST | `/accounts/create` | 新增账户，字段：`name`（≤32 字）、`kind`（`cash`/`alipay`/`wechat`/`bank`） |
| POST | `/accounts/<aid>/update` | 修改账户名称与类型 |
| POST | `/accounts/<aid>/delete` | 删除账户；至少保留一个账户 |

### 2.7 预算管理

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/budgets` | 预算页：当前月预算 + 近 6 个月执行历史 |
| POST | `/budgets/save` | 保存预算，字段：`year`（2000~2100）、`month`（1~12）、`amount`（正数，最多两位小数）；`amount` 为空或 `0` 表示取消该月预算 |

同一用户同一年月只有一条预算记录（数据库唯一约束 `uq_budget_user_month`），重复保存执行"更新"而非新增。

### 2.8 CSV 导出

`GET /export.csv` ｜ 需要登录

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| year / month / type / category_id / keyword | query | - | 否 | 与 `/records` 相同的筛选参数，导出当前筛选条件下的全部记录（不分页） |

返回：`Content-Type: text/csv`，UTF-8 BOM 编码。中文文件名先经 URL 编码，响应头只包含 ASCII 字符（`attachment; filename=records.csv; filename*=UTF-8''%E8%B4%A6...`），避免 WSGI 服务器按 latin-1 编码响应头时报 `UnicodeEncodeError`。列顺序为：日期、类型、分类、账户、金额、备注。

### 2.9 统计页

`GET /stats` ｜ 需要登录

返回 HTML 页面骨架（图表容器 + 筛选器），数据由下方 `/api/stats/*` 提供。

### 2.10 其他页面

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/register` | 注册页；字段 `username`（2~20 位中英文/数字/下划线）、`password`（6~64 位）、`confirm_password`、`nickname`（可选） |
| GET/POST | `/login` | 登录页；字段 `username`、`password`、`remember`（可选，`on` 表示记住登录）；支持 `next` 站内跳转 |
| GET | `/logout` | 退出登录（需要登录） |
| GET | `/csrf-error` | CSRF 校验失败时的提示页/JSON |
| GET | `/healthz` | 健康检查，返回 `{"status":"ok","db":"up"}`；数据库不可用时 503 |

## 三、数据接口（JSON）

所有数据接口都需要登录。成功统一为 `{"code":0,"msg":"ok","data":...}`。

### 3.1 Ajax 快速记账

`POST /api/records` ｜ 需要登录 ｜ 需要 CSRF

**请求体**（JSON，也接受表单）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| amount | string | 是 | 正数，最多两位小数，上限 99999999.99 |
| type | string | 是 | `expense` / `income` |
| record_date | string | 是 | `YYYY-MM-DD`，不早于 2000-01-01、不晚于今天 |
| category_id | int | 否 | 分类 id，必须属于当前用户且类型匹配 |
| account_id | int | 否 | 账户 id，必须属于当前用户 |
| note | string | 否 | 最多 200 字 |

**curl 示例**（登录后带 cookie 与 CSRF token，见第四节完整流程）：

```bash
curl -s -X POST http://127.0.0.1:5001/api/records \
  -b cookies.txt \
  -H "Content-Type: application/json" \
  -H "X-CSRFToken: $CSRF" \
  -d '{"amount":"23.50","type":"expense","record_date":"2026-10-29","note":"食堂午饭"}'
```

**成功响应**：

```json
{
  "code": 0,
  "msg": "记账成功",
  "data": {
    "id": 128,
    "amount": 23.5,
    "type": "expense",
    "type_label": "支出",
    "category": "餐饮",
    "category_color": "#f97316",
    "account": "微信",
    "record_date": "2026-10-29",
    "note": "食堂午饭"
  }
}
```

**失败响应**：

```json
{ "code": 1, "msg": "金额格式不对：只能是正数且最多两位小数（如 12.50）", "field": "amount" }
```

### 3.2 统计概览

`GET /api/stats/overview` ｜ 需要登录

| 参数 | 位置 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| year | query | int | 否 | 当前年 | 2000~2100，越界返回 400 |
| month | query | int | 否 | 当前月 | 1~12，越界返回 400 |

**成功响应**：

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "year": 2026,
    "month": 10,
    "income": 10842.0,
    "expense": 3316.4,
    "balance": 7525.6,
    "count": 57,
    "mom": { "expense_rate": 12.4, "income_rate": -3.1, "balance_rate": 0.0 },
    "yoy": { "expense_rate": null, "income_rate": null },
    "budget": {
      "amount": 3500.0,
      "spent": 3316.4,
      "remain": 183.6,
      "usage": 94.8,
      "level": "warn"
    }
  }
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `mom` | 环比（相对上月）增长率，单位 %；基期为 0 时为 `null` |
| `yoy` | 同比（相对去年同月）增长率，单位 %；基期为 0 时为 `null` |
| `budget.amount` | 本月预算；未设置时为 `0` |
| `budget.spent` / `remain` | 已花金额 / 剩余金额，超支时 `remain` 为负数 |
| `budget.usage` | 预算使用率（%）；未设置预算时为 `0` |
| `budget.level` | `none`（未设置）/ `normal`（<80%）/ `warn`（≥80%）/ `over`（≥100%） |

**失败响应**（参数越界）：

```json
{ "code": 1, "msg": "参数 month 超出范围（1~12）", "field": "month" }
```

| month | query | int | 否 | 当前月 | 1~12 |
| type | query | string | 否 | `expense` | `expense` / `income` |

**成功响应**：

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "items": [
```

## 四、curl 联调示例（完整登录流程）

服务端使用 Session Cookie，因此 curl 需要先用 cookie jar 保存会话，再从页面里取 CSRF token。

```bash
# 0. 变量准备
BASE=http://127.0.0.1:5001
JAR=/tmp/ledger_cookies.txt

# 1. 获取登录页（顺带建立会话并取 CSRF token）
curl -s -c "$JAR" "$BASE/login" -o login.html
CSRF=$(grep -o 'name="csrf-token" content="[^"]*"' login.html | sed 's/.*content="//;s/"//')
echo "CSRF=$CSRF"

# 2. 登录（表单字段：username / password / csrf_token）
curl -s -i -b "$JAR" -c "$JAR" -X POST "$BASE/login" \
  --data-urlencode "csrf_token=$CSRF" \
  --data-urlencode "username=demo" \
  --data-urlencode "password=demo123456" \
  | head -n 5

# 3. 快速记一笔（JSON + X-CSRFToken 头）
curl -s -b "$JAR" -X POST "$BASE/api/records" \
  -H "Content-Type: application/json" \
  -H "X-CSRFToken: $CSRF" \
  -d '{"amount":"23.50","type":"expense","record_date":"2026-10-29","note":"食堂午饭"}'

# 4. 统计概览
curl -s -b "$JAR" "$BASE/api/stats/overview?year=2026&month=10"

# 5. 分类占比饼图（只看收入）
curl -s -b "$JAR" "$BASE/api/stats/category-pie?year=2026&month=10&type=income"

# 6. 导出当前筛选条件的 CSV
curl -s -b "$JAR" "$BASE/export.csv?year=2026&month=10&type=expense" -o records.csv
head -c 3 records.csv | xxd    # 应为 UTF-8 BOM：ef bb bf

# 7. 未登录调用 API（不带 cookie，应返回 401 JSON）
curl -s -H "Accept: application/json" "$BASE/api/stats/overview"
```

## 五、字段校验规则汇总

| 字段 | 规则 | 错误提示示例 |
| --- | --- | --- |
| 金额 amount | 正数，最多 8 位整数 + 2 位小数，上限 99999999.99，不接受科学计数法 | 金额格式不对：只能是正数且最多两位小数（如 12.50） |
| 日期 record_date | 严格 `YYYY-MM-DD`（四位年、两位月、两位日，先用正则校验），不早于 2000-01-01，不晚于今天 | 日期不能晚于今天 |
| 类型 type | 白名单 `expense` / `income` | 收支类型不合法 |
| 备注 note | 最多 200 字 | 备注最多 200 个字 |
| 用户名 username | 2~20 位中英文、数字或下划线 | 用户名需为 2~20 位中英文、数字或下划线 |
| 密码 password | 6~64 位 | 密码至少 6 位 |
| 分类/账户 id | 必须存在且属于当前用户；分类类型需与 `type` 一致 | 分类不存在或已被删除 / 分类与收支类型不匹配 |
| 分页 page | 整数，1~999999；非法值回落第 1 页 | 页码参数不合法，已为你显示第 1 页 |
| 统计 year / month | 年 2000~2100、月 1~12，越界返回 400 | 参数 month 超出范围（1~12） |
